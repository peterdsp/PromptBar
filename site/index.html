Questions

Which chats does it work with?

Any chat that runs in a browser tab. Paste its address, give it a name and a colour. PromptBar ships with none, so you choose.

Can I use my own API key?

Yes. Add any OpenAI-compatible endpoint, hosted or on your own machine, such as localhost:11434. The key goes to the macOS Keychain.

What leaves my Mac?

Only your messages, sent straight to the address you set. There is no account, no analytics, no telemetry and no relay.

Which Mac do I need?

macOS 26 Tahoe or later, on Apple silicon or Intel. Builds are signed and notarised.

Ko-fi or App Store?

The same app. Ko-fi (€8.99) unlocks the direct build and it updates from GitHub. The App Store ($9.99) handles updates and Family Sharing. The GitHub trial is free.
